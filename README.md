# BasesDeDatos_QMB
## 01 - Creación de una base de datos y tablas en MySQL.

Alumna: Querén Mercado Bernardino.
Docente: Marisol Juárez.
----
- Crear una base de datos "escuela" con tres tablas diferentes dentro de ellas: estudiante, profesor y materia.

Instrucciones de la actividad:
1. Crea un repositorio en GitHub agregando el archivo README.md y posteriormente clónalo en tu equipo. 
2. Dentro del repositorio clonado deberás:
Editar el archivo README.md con una breve descripción de la práctica; 
Crear el archivo evidencias.md donde expliques paso a paso lo que realizaste; 
Crear una carpeta capturas donde guardarás las imágenes utilizadas como evidencia. 
En el archivo evidencias.md deberás insertar las capturas correspondientes y acompañarlas con una breve explicación de lo que realizaste en cada paso (Recuerda utilizar la ruta adecuada para poder visualizar las imágenes. Es decir, si las imágenes están dentro de la carpeta capturas, la ruta será: capturas/nombre_imagen.extensión.  
Al finalizar, guarda y sube tus cambios al repositorio utilizando Git.
En classroom, agrega la URL de tu repositorio, ya sea en un documento, como enlace o mediante un mensaje privado dentro de la actividad.
No olvides hacer clic en el botón ENTREGAR.
